## 6. 高级设置面板（`_build_advanced_panel` / `_build_advanced_groups` / `_field_row` 等）

结构：右侧面板 460px 宽，surface_alt 底；分组标题可折叠；字段行 = 右对齐标签（width 12）+ 控件。

| 控件 | 状态 | 问题 |
|---|---|---|
| 面板头「高级设置」+「收起」按钮 + 说明「一般不用改，改动会影响之后整理的文件。」 | 常态 | 无搜索/过滤框，87 个控件只能靠滚动找 |
| 滚动 Canvas + Scrollbar | 悬停（进入面板后接管滚轮） | **`bind_all` 全局滚轮劫持**（`_bind_panel_wheel`/`_unbind_panel_wheel`）：指针在面板内时全窗口滚轮都滚面板，离开时解绑——是全局 hack，与其他滚动区冲突 |
| 分组标题按钮「▸ 页面」↔「▾ 页面」 | 常态/悬停/展开/收起 | **「▸」「▾」文本三角字符画**，直接违反「无字符图形当图标」 |
| 字段行 × 85（Entry/Combobox/Checkbutton/Spinbox） | 常态/聚焦 | ①**分组名 = config JSON 节名照搬**（页面/正文/标题/图片/表格/参考文献 = page/body/headings/figure/table/references）；②**没有当前生效值展示**，行里只有控件本身；③**默认值不透明**：看不出哪个值来自学校模板、哪个被改过；④**没有恢复默认**（只有全局「恢复默认设置」菜单）；⑤Combobox `state="normal"` 可编辑，能输入非法字体名/字号，垃圾值直通 config；⑥Spinbox 无范围校验 UI，越界要到下次载入配置才报错；⑦**排版术语直露**：上边距(cm)、行距(倍)、首行缩进(字)、段后(pt)、悬挂缩进(pt)、字号（初号~八号无磅值对照）；⑧页码字段混在「页面」组；标题 4 级 × 8 字段 = 32 行无差异化命名（都叫「中文字体/字号/行距…」） |
| 「示例文档」组（文件名 Entry + 保存路径 Entry + 浏览… + 生成示例文档按钮 + 说明） | 常态 | **不是设置**，混在设置面板里；与菜单「生成示例文档」功能重复 |

## 7. 字符图形全量清单（必须全数替换）

| 字符/画法 | 位置 | 替换方案 |
|---|---|---|
| `▸` / `▾`（U+25B8/U+25BE 文本三角） | 分组标题 `_group()` | 分组不再折叠（常展开 + 过滤框），组头用 Segoe 图标 |
| 虚线矩形 `dash=(6,4)` | 拖放区 `_draw_drop()` | 图标字体文档图形（Document U+E8A5）+ 两行文案 + 实色边框 |
| 「·」圆点（U+00B7） | 结果区列表符号、文件信息分隔 | 保留：属正文排版符号，非图形图标（已在 lint 白名单） |
| 「…」省略号后缀（选择文档…、更改…、浏览…） | 按钮/菜单 | 保留：系统惯例 |
| `…` 截断长路径 | `_shorten_path` | 保留：正文截断 |

## 9. 结论（驱动 v0.8 范围）

1. 字符图形两类（▸/▾、虚线框）全数消灭，换 Segoe 图标字体系统。
2. 高级设置面板按用户目的重新分组（见 ia-regroup.md），行结构改为
   图标 + 名称 + 当前生效值 + 尾部控件；过滤框 + 每组恢复默认 + 默认值透明标记。
3. 示例文档移出面板（菜单已有入口）。
4. 滚轮改局部绑定（递归绑定面板子控件），删除 `bind_all`。
5. 下拉全部 readonly；数字行加输入校验与范围钳制。
6. 主流程三步拉开字重/字号/列宽层级；拖放区重画；聚焦环补齐。
