# 任务关脚本：非技术用户无求助完成任务（v0.8 验收）

要求：至少 1 人（最好 3 人），完全不懂排版/不懂编程的人；全程不许求助、
不许查资料；主试人只念开场白，之后只计时和记录，不解释、不提示。
有任何一次求助或提问即判「回炉」，修完重测。

## 准备

- 双击 `dist\DocFormatter.exe` 启动（不要给 python 命令）。
- 计时器（手机即可）。
- 记录表（下方）。

## 开场白（原样念）

「这是一个论文整理软件。请你做四件事：打开高级设置，把页码的位置改成
靠左，然后把这个改动撤销掉，最后把高级设置收起来回到主界面。
现在开始，我计时。」

（注：不演示、不指位置、不解释词义。）

## 任务步骤（主试人核对，不提示）

1. 打开「高级设置」（右上角入口）。
2. 找到「页码」分组（可用顶部过滤框输入「页码」，也允许滚动找）。
3. 把「页码位置」从 居中 改为 左。
4. 用「页码」组的「恢复默认」把改动撤回（行上「已修改」标记消失即成功）。
5. 收起高级设置，回到主流程。

## 判定

- 全程无求助完成：通过，记录用时。
- 有求助/提问/超时（>3 分钟）或改错位置：回炉（记录卡点，改版后重测）。
