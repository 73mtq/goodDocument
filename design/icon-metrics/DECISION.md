# 图标对齐路线定案（v0.8.1）

结论：**Route A——保留字体渲染 + 按字体单位解析预测墨迹盒 + 稀疏校准表吸收 grid-fit 离群值**。
零新增运行时依赖，保留 ClearType 原生渲染与免费换色。

## 一、根因（三层，全部实测确认）

1. **居中模型错误**：`tk.Label`/`create_text`（默认 anchor="center"）居中的是字体**行盒**。
   Segoe Fluent Icons 与 Segoe MDL2 的三套度量（hhea / OS/2 usWin / typo）完全一致：
   ascent=2048、descent=0、lineGap=0（unitsPerEm=2048）——行盒恰为 1em，**基线压在行盒底边**，
   字形墨迹全部从基线向上长。因此墨迹只占行盒下半部：矮字形（check 墨迹高 0.53em）沉底，
   满格字形占满——「每个图标偏得不一样」的直接机制。
2. **尺寸单位错误**：图标 token（16/20/40，设计像素）被当作 tk **points** 传入
   `font=(family, size)`。Windows 上 tk scaling = dpi/72，设计基准为 dpi/96，
   故任何缩放下图标恒放大 4/3（150% 时 16 设计px → 32px 行盒，设计意图 24px）。
3. **两套回退字体逐字形差异大**：同码点墨迹盒不同（如 font：Fluent 1.0em vs MDL2 0.75em 高），
   单一常数补偿在数学上不可能，必须逐字体、逐字形取数。

## 二、Route A 可行性实验（probe_gdi_placement.py，真屏 GDI 渲染 + 截图量测）

预测式（被实验证实成立）：tk 文本项行盒 = advance × linespace = 1em × 1em 方格、基线在底，
故行盒左上为原点时墨迹中心 = `((x0+x1)/2·s/upm, s − (y0+y1)/2·s/upm)`，
把文本摆到「预测墨迹中心 = 格心」，截图实测残差：

- 样本：8 个形态各异字形（check/view/table/font/settings/chevron_right/warning/play）
  × 2 字体 × 4 档像素（16/24/30/60）= 64 格，全检出、尺寸全对。
- 结果：**按「分量公差」61/64 达标**；残差 39 格恰为 (0,0)，其余 ±0.5px（墨迹盒整数边缘的量测粒度）。
- 唯一系统性离群：**warning**（三角+叹号）在 16/24ppem 纵向 +1px（两套字体同现）——GDI
  网格对齐（grid-fit）所致，属字形×ppem 的确定性函数，可用校准表吸收。

公差（承接任务规范，按分量计）：≤0.5px@100%、≤0.75px@125%、≤1px@150%
（设计 16/20/40 token 对应 ppem 见 calibration_report.json）。

## 三、定案与依据

| 维度 | Route A 字形补偿 | Route B Pillow 栅格化 PhotoImage |
|---|---|---|
| 对齐确定性 | 预测式 + 稀疏校准表，实测残差 0~±0.5px | 构造即精确（≤0.125px） |
| 依赖 | **零新增**（字体单位表为构建期生成常量） | 新增 Pillow（约 +4MB exe） |
| 渲染质感 | ClearType 原生 | Pillow 光栅化 |
| 换色状态（accent 白图标等） | 免费（itemconfigure fill） | 每色重渲染 |
| 授权 | 与现状相同：系统字体本地渲染，不捆绑 | 同 |

Route B 的唯一优势（构造性精确）被 Route A 的实测残差（≤量测粒度）覆盖，
故取 Route A；校准表只收 |分量残差| ≥ 0.75px 的确定性离群（现为 warning 族），
±0.5px 粒度不修（本身在公差内，修了反而过校正）。

## 四、量具工程记录（探针迭代中仪器失真的教训，供复用）

1. 截图量测一律用**画布内白色矩形框作绝对基准**（闭合外环、连通、尺寸自证），
   禁止从底色反推格子——环形字形会把底色劈成多块连通域。
2. Tk 的 highlight 环几何先后两次坑：环从 width/height 内/外抠的假设都错过，
   最终仪器完全不依赖 widget 几何（框和墨迹同画布同坐标系，框即基准）。
3. 每格唯一底色方案在 ClearType fringe 下会串色（fringe 像素可撞上邻格色），已废弃。
4. 窗口必须 `geometry("+40+40")` 固定位置且总宽 < 屏宽，否则右侧格被裁、
   兜底阈值会把别的格测进来（「误差随序号累加」即此症状）。
5. 实测与预测必须同定义：墨迹**包围盒**中心（不是亮像素质心——质心被笔画粗细拉偏）。

## 五、遗留风险与对策

- grid-fit 残差是 (字体文件, 字形, ppem) 的确定函数；同字体文件随 Windows 分发，
  表可迁移。但渲染模式（ClearType/灰度）变化可能移动 AA 边缘 ±1px——
  屏上量具（test_icon_alignment）在本机复测兜底，发现漂移即红。
- 校准/验收依赖 dev 依赖（fontTools/numpy/Pillow），运行时零依赖；
  无字体/无显示环境一律 skip 或走纯文字回退（既有契约不变）。
